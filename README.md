# HeadLab — Android project

Native Android demo app written in Kotlin. The head-size slider changes a character rendered inside this app only. The launch button opens Standoff 2 if it is installed; it does not modify the game, inject code, or affect other players.

## Build APK on GitHub
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. Open **Actions** and run **Build Android APK**, or push to `main`.
4. Open the completed workflow run and download the `HeadLab-debug-apk` artifact.

The artifact contains `app-debug.apk`. This is a debug build for testing, not a Play Store release.
